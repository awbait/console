# Журнал изменений Console

Перед созданием или редактированием записи прочитай
[скилл changelog](../skills/changelog/SKILL.md).
Он задаёт единые правила текста, тона, перевода и проверки.

Здесь хранятся только соглашения этого проекта:

- Языки: английский и русский, журналы `CHANGELOG.md` и `CHANGELOG.ru.md`.
- Ожидающие записи: по одному файлу в `changelog.d/`, оба языка в одном файле.
  Формат и команды описаны в [README](../../changelog.d/README.md).
- В журналах нет секций `Unreleased`; не добавляй туда ожидающие записи вручную.
- Изменения самих чартов записываются в журнал соответствующего чарта в его
  репозитории; здесь описывается поведение портала.
- Ветки, PR и выпуск: [git-workflow](../skills/git-workflow/SKILL.md).
- При исправлении уже выпущенной записи обновляй оба языка и соответствующее
  описание GitHub Release, если оно опубликовано.

Если о проблеме сообщила внешняя команда, добавь в конец соответствующей
записи `**Нашли:** DBA` и `**Reported by:** DBA` с фактическим названием
команды. Подпись остаётся в том же абзаце, не отдельной строкой.
Не указывай имена людей, номер issue или ссылку на PR и не дублируй подпись
во всех записях о связанных изменениях.
