### Added

#### en
You can now open "Service configuration" from the header of the "General information" tab on an existing order and edit the full `values.yaml` file to update several settings at once. The editor shows the line and column of YAML syntax errors as you type, and the "Changes" tab lets you compare the current and edited configuration line by line before submitting. Use "Check" to validate the configuration against the service's schema and rules without saving. Before saving, the portal checks that the service ID, namespace name fields, and read-only fields are unchanged. The window opens in read-only mode and explains why if you lack edit permissions, the order is a draft, a previous change is still being applied, the configuration is out of sync with Git, or the service is still deploying.

#### ru
В карточке существующего заказа окно «Конфигурация сервиса» теперь открывается из шапки вкладки «Общая информация». В нём можно редактировать весь файл `values.yaml` и менять несколько настроек за раз. Редактор проверяет синтаксис YAML по мере ввода и указывает строку и столбец ошибки. На вкладке «Изменения» можно построчно сравнить текущую и новую конфигурацию перед отправкой. Кнопка «Проверить» проверяет конфигурацию по схеме и правилам сервиса без сохранения. При сохранении портал проверяет, что идентификатор сервиса, поля имени пространства имён и поля только для чтения остались прежними. Окно открывается только для просмотра и объясняет причину, если у вас нет прав на редактирование, заказ в черновике, предыдущее изменение ещё применяется, конфигурация расходится с Git или сервис ещё разворачивается.
