### Added

#### en

In the order form, single-line and multi-line text fields with chart defaults now have “Copy value” and “Reset value” actions, each with a tooltip explaining its effect. While a field is empty, its default appears in grey and is not saved with the order, so the current chart default applies and updates with newer chart versions. “Copy value” puts the default in the field as editable text and saves it with the order, so newer chart defaults do not replace it. “Reset value” clears the field so the chart default applies again and follows newer versions. Chart authors no longer need to prefill these fields in the order form just to make a default editable.

#### ru

В форме заказа у однострочных и многострочных текстовых полей со значением по умолчанию из чарта появились действия «Скопировать значение» и «Сбросить значение». Подсказка у каждого действия объясняет его последствие. Пока поле пустое, значение по умолчанию отображается серым и не сохраняется в заказе, поэтому применяется значение из текущей версии чарта и меняется при переходе на новую версию. Действие «Скопировать значение» помещает значение по умолчанию в поле как редактируемый текст и сохраняет его в заказе, поэтому новые значения из чарта его не заменят. Действие «Сбросить значение» очищает поле, чтобы снова применялось значение по умолчанию из чарта и обновлялось с новыми версиями. Авторам чартов больше не нужно заранее заполнять такие поля в форме заказа, чтобы значение по умолчанию можно было изменить.
