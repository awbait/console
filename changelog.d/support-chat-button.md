### Added

#### en

Added a support chat button in the bottom-right corner of every portal page. It opens the platform support chat in a messenger in a new tab. Occasional hints next to the button invite you to ask questions or report problems. You can dismiss the hints with the close icon while keeping the button available. Administrators set the chat address using the `SUPPORT_CHAT_URL` environment variable. The button is hidden if the variable is not set.

#### ru

Добавили кнопку чата поддержки в правом нижнем углу каждой страницы портала. Она открывает чат поддержки платформы в мессенджере в новой вкладке. Рядом с кнопкой время от времени появляются подсказки, что в чат можно обратиться с вопросами и проблемами. Подсказки можно скрыть крестиком, при этом кнопка остаётся доступной. Администратор задаёт адрес чата переменной окружения `SUPPORT_CHAT_URL`. Если переменная не задана, кнопка не отображается.
