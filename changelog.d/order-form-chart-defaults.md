### Fixed

#### en
The order form no longer blocks submission when required parameters have service defaults, including parameters hidden from the form. Default values appear as hints, with dropdowns and checkboxes set to their default states. Required parameters without defaults still need to be filled in.

#### ru
Форма заказа больше не блокирует отправку, если у незаполненных обязательных параметров есть значения по умолчанию, в том числе у скрытых параметров. Значения по умолчанию показаны в подсказках, а в списках и флажках уже выбраны соответствующие варианты и состояния. Обязательные параметры без значений по умолчанию по-прежнему нужно заполнять.
