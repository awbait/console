### Added

#### en
Service owners can now define a namespace name template so orders deploy to the namespace the chart actually creates. The order form previews the name as the required fields are filled in.

#### ru
Владельцы сервисов теперь могут задать имя namespace по шаблону, чтобы заказ устанавливался в тот namespace, который чарт создаёт в кластере. Форма заказа заранее показывает имя по мере заполнения нужных полей.
