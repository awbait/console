### Added

#### en

Service owners can now enable multiline input for string fields in the order form by setting `"ui:widget": "textarea"` in the view document. Line breaks are preserved in values, making it suitable for banner text, message templates, or addresses entered one per line.

#### ru

Владельцы сервисов теперь могут включить многострочный ввод для строковых полей формы заказа, указав `"ui:widget": "textarea"` в view-документе. Переносы строк сохраняются в values, что удобно для текста баннера, шаблона сообщения или адресов по одному в строке.
