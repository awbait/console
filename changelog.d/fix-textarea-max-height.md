### Fixed

#### en

Long multi-line fields in the service order form now grow to about 16 lines before scrolling inside the field. Dragging a field’s corner is limited to the same height, so long values and grey default text no longer stretch the form across several screens. In an empty field, “Default” now appears on its own line, with the suggested value below. No action is needed.

#### ru

Длинные многострочные поля в форме заказа услуги теперь увеличиваются примерно до 16 строк, а затем прокручиваются внутри поля. При растягивании за угол действует то же ограничение по высоте, поэтому длинные значения и серый текст со значением по умолчанию больше не растягивают форму на несколько экранов. В пустом поле слова «по умолчанию» теперь стоят на отдельной строке, а значение начинается ниже. Ничего делать не нужно.
