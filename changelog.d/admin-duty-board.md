### Changed

#### en

Redesigned the “Overview” page in Console administration to show whether the platform needs attention. It now shows users online, active users, new orders, and user actions on orders, with mini charts and comparisons with yesterday. “Needs attention” lists failures before warnings, covering orders, stands, integrations, storage, background tasks, settings, and maintenance. Each entry shows the service, team, stand, and time, with a link to where the problem can be resolved. The full list opens in a side panel. The overview also shows platform health, orders and stand operations in progress, the approval queue, and recent events. Data refreshes automatically, with the last update time beside the page title. If the connection to Console is lost, the page shows how long the data has been stale. Online and active user charts start collecting data with this version, so they will be short during the first few days. Removed the “Sections” block that duplicated the menu and the publication counters. Publication counters remain on the “Publications” page.

#### ru

Переделали страницу «Обзор» в разделе администрирования Console: теперь она показывает, требует ли платформа внимания. На странице видны пользователи онлайн, активные пользователи, новые заказы и действия пользователей с заказами, с мини-графиками и сравнением со вчера. В блоке «Требует внимания» сначала показаны сбои, затем предупреждения по заказам, стендам, интеграциям, хранилищам, фоновым задачам, настройкам и техническим работам. В каждой строке видны сервис, команда, стенд и время, есть ссылка туда, где можно исправить проблему. Полный список открывается в боковой панели. На обзоре также видны состояние платформы, заказы в процессе и операции над стендами с прогрессом, очередь согласования и последние события. Данные обновляются автоматически, время последнего обновления показано рядом с заголовком. При потере связи с Console видно, с какого времени данные не обновлялись. Графики пользователей онлайн и активных пользователей начинают накапливаться с этой версии, поэтому в первые дни они будут короткими. Убрали блок «Разделы», который повторял меню, и счётчики публикаций. Счётчики остались на странице «Публикации».
