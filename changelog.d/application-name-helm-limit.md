### Fixed

#### en
Long names of new orders no longer prevent Helm charts from rendering in Argo CD. Application names longer than 53 characters are shortened with a suffix that distinguishes the full names. Existing orders keep their Application names.

#### ru
Длинные имена новых заказов больше не мешают Argo CD сформировать ресурсы из Helm-чарта. Имена Application длиннее 53 символов сокращаются с постфиксом, который различает полные имена. Существующие заказы сохраняют прежние имена Application.
