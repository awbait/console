### Changed

#### en
The changelog is now collected on release from the entries in `changelog.d/`, one
file each, so two branches no longer write into the same line of it.

#### ru
Журнал изменений теперь собирается на релизе из записей в `changelog.d/`, по
файлу на запись, и две ветки больше не пишут в одну и ту же его строку.
