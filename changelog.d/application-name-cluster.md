### Fixed

#### en
With the default naming template, the same service for the same team and chart can now be ordered into the same namespace on different clusters within one stand without Argo CD Application name conflicts. Existing orders keep their Application names.

#### ru
Со стандартным шаблоном имён один и тот же сервис одной команды и чарта теперь можно заказать в один namespace на разных кластерах одного стенда без конфликта имён Argo CD Application. Существующие заказы сохраняют прежние имена Application.
