### Fixed

#### en
The order form builder now reports an error when validating a view document if a tab points to a list of strings, numbers, or booleans. Display these lists as regular list fields in a form, since tabs require lists of objects.

#### ru
В «Конструкторе формы заказа» теперь появляется ошибка при проверке документа вида, если вкладка ссылается на список строк, чисел или логических значений. Показывайте такие списки обычными полями-списками в форме, поскольку вкладкам нужны списки объектов.
