### Changed

#### en
The order form now follows the chart’s rules for hiding fields in each mode, including fields in nested sections and list rows. These fields no longer need to be filled in or show validation errors.

#### ru
Форма заказа теперь учитывает правила чарта для скрытия полей в каждом режиме, в том числе во вложенных разделах и строках списков. Эти поля больше не требуется заполнять, и ошибки по ним не показываются.
