### Added

#### en
Administrators can set a shared value for each variable and, when needed, a separate value for each stand. When an order is saved, the portal uses the value for the selected stand or the shared value if no stand value is set. An empty shared value now prevents an order from being saved on a stand without its own value. Previously, the portal used an empty string.

#### ru
Администраторы могут задать общее значение переменной и, при необходимости, своё значение для каждого стенда. При сохранении заказа портал использует значение выбранного стенда или общее значение, если для стенда оно не задано. Теперь пустое общее значение останавливает сохранение заказа на стенде без своего значения. Раньше портал подставлял пустую строку.
