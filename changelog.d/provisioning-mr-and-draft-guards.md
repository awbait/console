### Fixed

#### en
Fixed order lifecycle bugs where closing a stand regeneration merge request permanently locked a running order, a conflicted deletion merge request could be rewritten as an update, and submitting a saved draft bypassed chart version availability checks.

#### ru
Исправили ошибки жизненного цикла заказов: закрытие merge request при перегенерации стенда больше не блокирует работающий заказ, конфликтный merge request на удаление не подменяется обновлением, а отправка сохранённого черновика теперь проверяет доступность выбранной версии чарта.
