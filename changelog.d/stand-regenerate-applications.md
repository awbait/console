### Added

#### en

Added an action on the stand page to regenerate application.yaml for existing orders after stand settings change. The background task opens a merge request for each order whose file differs from Git and shows progress and errors.

#### ru

На странице стенда добавили перегенерацию application.yaml существующих заказов после смены настроек стенда. Фоновая задача открывает merge request для каждого заказа, чей файл отличается от сохранённого в Git, и показывает прогресс и ошибки.
