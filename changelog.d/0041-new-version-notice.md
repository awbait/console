### Added

#### en
Added a banner at the top of every open page when a new portal version is available. It reminds you to finish and save your work in forms before reloading, provides a reload button and a “What’s new” link to the release notes on the “About” page. You can dismiss the banner. If a screen cannot open because the page is still using an older portal version, the page automatically reloads once and opens that screen.

#### ru
Добавили уведомление о новой версии портала вверху каждой открытой страницы. Оно напоминает завершить работу с формами и сохранить изменения перед перезагрузкой, содержит кнопку перезагрузки и ссылку «Что нового» на список изменений на странице «О портале». Уведомление можно закрыть. Если экран не открывается из-за того, что страница использует старую версию портала, страница автоматически перезагружается один раз и открывает этот экран.
