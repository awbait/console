### Added

#### en
You can now copy an order to another stand from the orders list or the order page. This creates a draft of the same service and version in the same team. Values from variables are filled in again for the new stand, while other values are preserved. Review the draft, make any changes you need, and submit it as a regular order.

#### ru
Теперь заказ можно скопировать на другой стенд из списка заказов или со страницы заказа. Будет создан черновик того же сервиса и версии в той же команде. Значения из переменных подставятся заново для нового стенда, а остальные значения сохранятся. Проверьте черновик, при необходимости измените параметры и отправьте его как обычный заказ.
