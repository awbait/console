### Added

#### en

Added an optional Argo CD path in stand settings for mirrors or repositories stored under a different path. The portal continues saving order files to the configured GitLab path.

#### ru

В настройках стенда добавили необязательное поле «Путь для Argo CD» для зеркал или репозиториев под другим путём. Портал продолжает сохранять файлы заказов по пути из поля «Путь в GitLab».
