### Fixed

#### en
Fixed form rendering and validation edge cases for objects with both fixed and additional properties, optional nested objects when adding list items, optional or null variant choices, and fields that accept multiple JSON types.

#### ru
Исправили ошибки в форме заказа: дополнительные ключи в объектах с известными полями теперь доступны на всех уровнях и не теряют числовые ключи при обновлении, добавление элементов списка не блокирует сохранение из-за пустых необязательных секций, а необязательные варианты и поля с несколькими типами работают без ложных ошибок.
