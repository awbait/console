### Added

#### en
You can now choose a Git layout and GitLab path for each stand: a group with separate team permissions or a single repository without that separation. The layout and path cannot be changed while the stand has orders other than drafts or deleted orders. Each stand now has a page with GitLab access checks, Argo CD checks, and manifests that you apply manually once per stand. The portal creates nothing in Argo CD. Git imports now scan each stand’s path and assign discovered orders to that stand.

#### ru
Теперь для каждого стенда можно выбрать раскладку в Git и путь в GitLab: группу с разделением прав по командам или один репозиторий без такого разделения. Раскладку и путь нельзя менять, пока на стенде есть заказы, кроме черновиков и удалённых. У каждого стенда появилась страница с проверками доступа к GitLab, проверками Argo CD и манифестами, которые нужно применить вручную один раз на стенд. Портал ничего не создаёт в Argo CD. Импорт из Git теперь обходит путь каждого стенда и привязывает найденные заказы к нему.
